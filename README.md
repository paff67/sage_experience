# 原著指导：自用修订版

用于现有「原著指导」角色卡的酒馆助手脚本。保留原脚本及其角色设定、提示词、界面和资源引用；此仓库不是独立数据库插件，也不是完整角色卡。

## 使用

在原角色卡的酒馆助手脚本管理中，编辑现有「原著指导」脚本，将代码替换为：

```js
import 'https://gcore.jsdelivr.net/gh/paff67/sage_experience@v1.0.0/index.js';
```

保留原脚本条目的 ID、数据和启用设置。不要另建一个同名脚本与旧版同时启用，以免重复注册事件和发起请求。等待正在进行的任务结束后刷新页面加载。

依赖现有角色卡的扩展字段、世界书及 SillyTavern / TavernHelper 环境。原著资源仍由脚本中的原资源地址提供。仅导入此文件不会安装完整角色卡或独立数据库。

固定版本不会自动更新。后续升级请改用经过验证的新版本标签；需要跟随最新提交时可使用 `@main`，但 CDN 缓存可能延迟更新。

## 本版改动

- API 方案增加请求超时，默认 120 秒，允许 1～3600 秒；模型列表仍独立限制为 20 秒。
- 纪要 SQL 内容完整、仅缺少 `tableEdit` 结束标签时，使用原解析器完整校验后接受；不补写字段、不丢弃残缺语句。
- 上游余额/支付错误与空文本错误分开提示。
- 上游返回 `content_filter` 时停止解析与保存，明确提示输出可能被截断。

格式兜底不能恢复被截断的对白或正文。`content_filter`、未闭合字符串和不完整 SQL 不会被伪造为成功结果。
